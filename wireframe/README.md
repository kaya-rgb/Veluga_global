# 벨루가 기업 랜딩 B안 · 데스크톱 와이어프레임

1920px 고정 폭의 스크롤형 와이어프레임. 첫 화면은 GNB 68px + 히어로 1012px = 1080px다.

최신 적용 상태: 히어로를 기업 메시지의 추상 모션으로 바꾸고, 기술 영역을 **역량별 탐색 + 관련 제품 설명**으로 구성했다. 고객 사례는 ‘서비스 활용 사례’, 채용 제목은 ‘AI가 바꿀 일의 모습을 / 함께 만들어가고 싶으신가요?’다. GNB는 ‘제품 / 채용 / 언어 선택’으로 정리하고 로고·제품·채용의 점프 이동을 해제했다. 최신 변경은 마지막 ‘GNB 메뉴와 점프 이동 정리’ 항목을 기준으로 한다. 아래 기록은 수정 순서에 따른 이력이다.

## 보기

이 폴더에서 `python3 -m http.server 8787 --bind 127.0.0.1`을 실행한다.

- `http://127.0.0.1:8787/preview.html`: 검토 화면. 기본은 창 너비 맞춤이며 전체 보기·100%·75%·50%, 12컬럼 그리드 표시를 지원한다.
- `http://127.0.0.1:8787/index.html`: 가로 1920px 원본.

## 적용 기준

- 콘텐츠: `../.design/company-landing/INFORMATION_ARCHITECTURE.md`의 B안 초안.
- 디자인: `../DESIGN.md`의 Desktop 그리드, Gray 팔레트, Pretendard, 등록 제목·본문 크기, GNB·중립 버튼 규격.
- 12컬럼, 거터 20px, 콘텐츠 1440px, 좌우 여백 240px. 컬럼 폭은 `(1440 - 11 × 20) / 12 = 101.666…px`로 계산한다.
- 와이어프레임이므로 브랜드·상태 색상을 사용하지 않는다. DESIGN.md의 Gray 계열만 사용한다.
- 새 간격과 패딩은 기본 4px 배수. 6px 창 표시 간격은 2px 배수 예외다. 1px 테두리, 글자 크기·행간·분할 컬럼의 계산값은 규격 그대로 사용한다.
- Pretendard 파일과 CSS를 전역 자산에서 `public/assets/fonts/pretendard`로 복사해 로컬 제공한다.
- 원본 로고를 재제작하지 않고 88 × 26px 로고 배치 영역을 둔다.
- Footer는 DESIGN.md의 기존 컴포넌트 정의 범위 밖이지만, 이번 사용자가 요청한 전체 콘텐츠 초안에 포함되어 있어 같은 그리드·Gray·타이포 규칙으로 배치했다. DESIGN.md는 변경하지 않았다.

## 인터랙션 및 미확정 콘텐츠

- GNB의 로고·제품·채용은 구조 표시만 하며 페이지 내 점프 이동을 하지 않는다. 별도 목적지는 미연결이다.
- Voost 시연 배치 영역은 해당 기술 본문으로 이동한다.
- 두 제품 카드의 ‘보러가기’ 버튼은 각 제품 사이트를 새 탭으로 연다. 고객 사례에는 서비스 이동 버튼을 두지 않는다.
- 고객 사례는 하단의 세 dots로 전환한다. 첫 번째는 산지니 AI, 나머지 두 개는 추가 사례 배치 영역이다.
- 인재풀 버튼은 폼 구조를 확인하는 모달을 연다. 등록·전송·저장은 구현하지 않았고 제출 버튼은 비활성화되어 있다.
- 언어 선택과 개인정보처리방침은 연결 예정 안내를 표시한다.
- 히어로는 흩어진 조각이 정돈된 형태로 바뀌는 추상 모션이다. 제품 카드의 데모는 영상 배치 영역으로 유지한다. 기술 영역은 역량별 목록을 선택하면 개념도와 관련 제품의 적용 방식이 나타나는 구조다. 실제 캡처나 검증 완료된 시연은 아니다.
- 히어로 모션은 멈춤·재생 버튼을 제공하며 화면 밖·비활성 탭에서 일시정지한다. 동작 줄이기 환경에서는 정적인 형태를 표시한다.
- 기술 목록은 마우스와 위/아래 방향키·Home/End로 전환한다. `#execution` 링크는 해당 패널을 먼저 표시한 뒤 이동한다.
- 확인된 고객 사례는 부산대학교 산지니 AI 1건이다. 벨루가 기능의 맞춤 구성 및 학생·교수 학습 지원은 사용자가 확인한 내용이다. 실제 서비스 화면 이미지는 배치 영역으로 표시한다.
- 투자사 영역은 제거하고 고객사만 남겼다. 고객 로고 이미지와 기업 문의 이메일은 교체 전 상태다.

## 범위

브라우저에서 검토하는 와이어프레임이며 사용자 요청으로 Vercel에 공유용 배포했다. 실제 서비스 기능 구현이나 Figma 편집은 하지 않았다. 검토 도구의 확대·축소는 원본 1920px 레이아웃을 변경하지 않는다.

배포 주소: https://veluga-global.vercel.app/preview.html. GitHub `main` 푸시로 자동 배포하며 빌드·경로 설정은 저장소 루트의 `README.md`와 `vercel.json`을 따른다.

## 벨루가 제품 범위 수정 · 2026-09-07

- 사용자가 제공한 네 가지 기능을 근거로 벨루가 유형을 ‘AI 챗봇·에이전트 플랫폼’으로 수정했다. 공개 제품 랜딩의 RAG 챗봇 설명으로 전체 기능을 한정하지 않는다.
- 히어로는 제작·활용·운영 확인, 제품 카드는 ‘AI 제작부터 업무 활용, 운영까지’로 요약했다. 챗봇 빌더·에이전트 빌더·스페이스·애널리틱스는 각 한 줄로 설명한다.
- 회사 소개와 FAQ의 벨루가 설명도 일치시켰다. 기술 첫 항목은 자료 기반 답변과 워크플로우를 통한 응답 흐름 설정을 보여준다.
- 애널리틱스는 접속자·메시지·키워드·미답변 질문 확인 범위다. 자동 최적화나 자동 학습을 주장하지 않는다.
- 새 그림은 기능 구성 도식이며 실제 제품 화면을 재현한 것은 아니다.

- 수정 후 브라우저에서 히어로·제품 카드·기술 첫 항목을 확인했다. 1920px 원본, 첫 화면 1080px, 전체 높이 6522px가 유지되며 가로 넘침이 없다. 기능 구성 패널과 히어로 도식의 텍스트 잘림도 없다.
- 언어 버튼의 16px 아이콘 표시를 보정하고 실제 크기와 선 색상을 확인했다. 미리보기 너비 맞춤에서도 가로 넘침이 없다.

## 미리보기 요소 선택 개선 · 2026-09-07

- 검토 화면의 iframe을 제거하고 `index.html` 본문을 같은 문서에 불러온다. 각 제목·문장·버튼을 브라우저 검토 도구에서 직접 선택할 수 있는 구조다.
- Chrome에서 제목과 제품 카드의 실제 클릭 위치가 해당 요소로 판정되는 것을 확인했다. 1920px 원본 크기, Pretendard, 너비 맞춤·전체 보기·그리드, 섹션 이동, FAQ 높이 갱신, 인재풀 모달 열기·닫기와 콘솔 오류 없음을 확인했다.
- Codex 앱의 주석 입력창은 자동 조작할 수 없어 입력·저장까지는 검증하지 못했다. 앱에서 미리보기를 새로고침하고 주석 모드를 켜서 최종 확인해야 한다.

- 사례 dots의 클릭과 ArrowRight·End로 세 슬라이드와 선택 표시를 확인했다. 2·3번은 ‘추가 고객 사례 / 사례 콘텐츠 배치 영역’만 표시하며 산지니 AI로 복원했다.
- 제품 버튼은 100×44px, 패딩 0/12/0/16px, 간격 4px, 반경 8px다. 표시 문구는 ‘보러가기’, 접근성 이름은 제품명을 포함한다. 대상 주소 `https://veluga.app/`, `https://veluga.ai/`와 새 탭 설정을 DOM에서 확인했다.

- 너비 맞춤·50%·전체 보기, 12컬럼 그리드 켜기·끄기를 실제 화면에서 확인했다. 그리드는 12개 열과 20px 거터이며 배율 변경 후에도 원본 치수를 유지한다.
- 잘못된 내부 hash 링크 0개, 로딩 실패 이미지 0개, 주요 제목·본문·표 셀의 텍스트 넘침 0개, 확인한 탭의 콘솔 warning/error 0건. 1px caption은 접근성용 숨김 요소다.

### 기술 영역의 확장 방식

- 현재 항목은 자료 기반 답변 / 응답 흐름 설계 / 도구 연결과 실행 / 사용·실행 관리다. 첫 두 항목은 벨루가만, 나머지 두 항목은 관련된 두 제품을 보여준다.
- 새 서비스는 관련 역량의 적용 제품 목록에만 추가한다. 새로운 기술을 다루면 역량 항목과 상세 패널을 추가한다. 전체 서비스를 기존 세 가지 또는 네 가지 역량에 맞춰 채울 필요가 없다.
- 탭 처리는 실제 DOM의 항목 수를 따르고 제품 목록은 Flex wrap, 패널은 최소 높이만 사용한다. 미출시 제품이나 Voost 고객 사례를 추가하지 않았다.
- 상세 문구와 정보 구조 참고 자료는 `../.design/company-landing/INFORMATION_ARCHITECTURE.md` 5.4에 기록했다.

## Voost 조직 운영·승인·보안 환경 차별점 · 2026-09-07

사용자의 설명과 [Voost 공식 랜딩](https://veluga.ai/#features)의 핵심 기능·관리자 기능·업무 실행 흐름 및 펼친 FAQ를 확인해 로컬 와이어프레임을 보완했다.

- 제품 카드 제목을 ‘조직의 기준 안에서 일하는 AI’로 변경했다. 복잡한 업무 실행과 함께 사용자 승인, 조직의 권한·정책 관리, 승인된 모델·연결 경로를 설명한다. 요약은 ‘사용자 승인 / 조직별 운영 / 보안 정책 적용’이다.
- 기존 실행 패널은 파일·앱·연결 시스템을 유지하며 변환·복사·재입력 단계를 줄이는 방식으로 보완했다. 사용·실행 관리 패널에는 중요한 변경·삭제·전송에 대한 사용자 승인과 기록을 명시했다.
- ‘조직별 AI 운영’과 ‘보안 환경 연결’을 독립 항목으로 추가했다. 테넌트·파트너 관리자, 사용자·모델·도구·예산, 비용·감사 기록, 내부 모델과 외부 접속 정책을 설명한다.
- 테넌트는 ‘조직별 운영 단위(테넌트)’로 먼저 설명했다. 공공기관·폐쇄망 관련 안내는 조직별 환경·정책에 따른 도입 전 확인 조건을 함께 표시한다.
- 제품 카드 본문의 최소 공간을 80px로 맞췄고 상세 패널은 역량 목록 높이에 맞춰 늘어나도록 했다. 기존 Gray 토큰과 개념도 표현을 사용한다.

검증: 정적 빌드와 `git diff --check` 통과. 실제 로컬 미리보기에서 두 제품의 영상 영역 높이·위치 일치, Pretendard 로딩, 여섯 패널의 텍스트·도식 잘림 없음을 확인했다. 여섯 항목을 클릭해 선택 탭과 표시 패널이 각각 한 개임을 확인했고, 마지막 탭에서 ArrowDown 순환, 첫 탭에서 End 이동, Voost 시연 영역에서 실행 패널 열기를 검증했다. 확인한 탭의 콘솔 warning/error는 없었다.

상세 문구와 출처·적용 범위는 콘텐츠 명세 5.3~5.4에 기록했다. 검증은 기업 랜딩의 표시·동작 기준이며, 실제 Voost 조직 운영이나 폐쇄망 구성에 대한 기능 시험은 아니다. 이번 수정은 로컬 반영 단계다.

## 기업 기술 역량 중심으로 정리 · 2026-09-07

기술 역량을 여섯 항목에서 네 항목으로 줄였다. Voost는 기존 업무 환경과 연결한 실행, 권한·정책·사용자 승인에 따른 실행 제어에 집중한다. 테넌트·파트너·사용량·비용 등 관리자 기능의 상세 설명을 덜어내고 ‘조직별 AI 운영’과 ‘보안 환경 연결’ 패널을 제거했다. 네 번째 항목은 ‘권한 기반 실행 제어’로 변경했다. 제품 카드는 유지했다.

기술 소개 문구는 사용자가 지정한 ‘벨루가는 제약적인 문제의 본질을 탐구하며 / 필요한 기술을 연결하고 발전시킵니다.’를 적용했다.

검증: 정적 빌드와 `git diff --check` 통과. 로컬 미리보기에서 네 탭을 클릭해 선택 탭과 표시 패널이 각각 하나임을 확인했다. 각 패널 높이는 544px이며 제목·본문·도식의 넘침은 없었다. 마지막 탭의 ArrowDown 순환과 첫 탭의 End 이동, Pretendard 로딩, 수정한 실행 제어 화면을 확인했다. 확인한 탭의 콘솔 warning/error는 없었다. 수정본을 로컬 미리보기에 열어 두었으며 이번 변경은 커밋·푸시·배포하지 않았다.

## 히어로 본문과 벨루가 자료 표현 · 2026-09-07

이후 사용자가 승인한 두 문구 수정을 반영했다. 벨루가 카드 제목·본문의 ‘우리 자료’를 ‘내 자료’로 변경하고, 히어로 본문은 ‘필요한 지식을 활용하고, 원하는 결과를 만들어낼 수 있도록. / 벨루가는 목적과 환경에 맞는 AI 제품을 만듭니다.’로 수정했다. 히어로 제목과 제품 공통 소개·푸터 등 제안만 했던 다른 문구는 유지했다.

검증: 로컬 브라우저에서 히어로 본문이 지정한 두 줄로 표시되고 벨루가 카드 제목·본문에 잘림이 없음을 확인했다. Pretendard 로딩, 정적 빌드, `git diff --check`를 확인했다. 기술 역량 정리와 이 문구 수정을 함께 배포하는 범위로 승인받았다.

## 기술 탐색 영역의 좌우 높이 정렬 · 2026-09-07

탭 목록의 남는 공간을 항목 사이에 고르게 배분해 첫 탭의 위쪽과 마지막 탭의 아래쪽을 우측 콘텐츠에 맞췄다. 버튼 크기와 우측 콘텐츠 높이는 유지한다. 네 탭 모두 로컬 브라우저에서 확인했으며 하단 차이는 약 81px에서 1px 미만으로 줄었다. 제목·본문·도식의 넘침과 콘솔 warning/error가 없고, 정적 빌드와 `git diff --check`를 통과했다. 이번 정렬 수정은 로컬에만 반영했다.

후속 요청으로 기술 영역 하단의 내부 모델·업무 시스템 연동 및 폐쇄망 적용 범위 안내 문구를 삭제했다. 로컬 화면에서 안내 영역이 제거되고 좌우 상하단 정렬이 유지되는 것을 확인했다.

## 제품 고유 용어를 사용 행동으로 설명 · 2026-09-07

첫 방문자가 제품 고유 용어인 ‘스페이스’를 몰라도 이해하도록 카드 본문은 ‘AI와 대화하고’, 영상 안내는 ‘챗봇 제작과 대화·업무 활용 과정’, 기술 적용 설명은 ‘AI와의 대화에 외부 도구를 연결해’로 변경했다. 기능 근거 문서의 원래 제품명은 유지한다. 로컬 화면에서 본문·기술 설명 두 줄, 영상 안내 한 줄과 잘림 없음을 확인했으며 Pretendard 로딩, 정적 빌드, `git diff --check`를 통과했다. 콘솔 warning/error는 없었다.

## 시연 영역 이동 제거와 기술 패널 제품명 정리 · 2026-09-07

Voost 업무 시연 영역을 링크에서 정적인 영상 배치 영역으로 변경했다. 클릭해도 기술 영역으로 이동하거나 실행 탭을 열지 않는다. 네 기술 탭 하단의 ‘벨루가에 적용 / Voost에 적용’은 제품명 ‘벨루가 / Voost’만 표시하고 기존 기술 적용 설명은 유지했다. 관련 콘텐츠 명세를 동기화했다.

검증: 원본과 너비 맞춤 미리보기에서 시연 영역을 클릭해 URL hash, 스크롤 위치, 선택 탭이 그대로 유지되는 것을 확인했다. 네 기술 탭을 전환해 다섯 제품명 표시와 텍스트·도식 잘림 없음을 확인했고 좌우 콘텐츠 상하단 차이는 0px이다. 정적 빌드와 `git diff --check`를 통과했으며 미리보기 콘솔 warning/error는 없었다. 이번 변경은 로컬에만 반영했다.

## 기술 활용 안내와 보조 설명의 위계 · 2026-09-07

네 기술 패널 하단에 ‘실제 제품에서 이렇게 사용되고 있어요.’를 공통 안내로 추가했다. 기술 설명이 먼저 읽히도록 하단 제품명은 14px·600·Gray 700, 설명은 14px·400·Gray 600으로 낮췄다. 안내는 14px·500·Gray 600으로 표시한다. 탭 우측의 화살표를 제거하고 선택 상태는 기존 배경색과 글자색으로 표시한다.

검증: 로컬 미리보기에서 네 탭을 실제로 전환해 안내가 패널별로 한 번만 표시되고 선택 탭·표시 패널이 각각 하나임을 확인했다. 화살표가 제거됐으며 실제 글자 크기·굵기·색상, Pretendard 로딩과 글자·도식 잘림 없음을 확인했다. 좌우 상하단 차이는 1px 미만으로 유지됐다. 정적 빌드와 `git diff --check`를 통과했다. 이번 변경은 로컬에만 반영했다.
